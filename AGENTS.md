# Project Guidelines

## Application
An Android application.

## Development rules
- Preserve existing working functionality.
- Follow the existing project architecture.
- Prefer Kotlin for new Android code.
- Avoid introducing dependencies unnecessarily.
- Keep UI state management consistent.
- Use structured concurrency and lifecycle-aware code.
- Add tests for new business logic.
- Do not hardcode credentials or tokens.

## Workflow
- Inspect existing code before making changes.
- Plan significant changes before implementation.
- Implement one feature at a time.
- Run relevant tests after modifications.
- Explain any tests that could not be executed.
- Do not push or merge without approval.
